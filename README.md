# NEONNET — NEON ASCENSION

A static fictional public network set in 2187: news, community forums, the GHC public Hunter Registry, organization directories, Gate Watch, an IGA field guide, public professional profiles, classifieds and a rumor-labelled NULL NODE.

## Run locally

Serve this folder with any static web server, then open `index.html` through that server. For example: `python -m http.server 8000`. Hash-based routes support direct links on GitHub Pages without server rewrites.

## Local interactions

Likes, upvotes, bookmarks, follows, polls, replies, new threads, reports and profile edits use browser localStorage with an in-memory fallback. They never reach other users. Marketplace interest does not send messages or process money. Clear local activity in the reader guide.

## Content and assets

The primary canon is the NEON ASCENSION website brief. Additional ordinary Hunter records, routine news, listings and incident feeds are explicitly fictional or illustrative. Public records are separated from unverified rumors. No private medical records, hidden motives or confirmed Gate origin are established.

Registered images load from `https://itschoco.github.io/neon-assets/`. Kissing expression 11 is never used. No image-generation prompts, account credentials or model settings are included.

## NULL NODE

Enter `/null` in search, or click the interrupted-channel advertisement three times. Connection and clearance are fictional local interface states. Terminal commands only navigate predefined files; they cannot execute code.
